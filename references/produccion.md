# Producción

Entrega storyboard con ID, sección de origen, acción o locución, plano/captura, B-roll, rótulos, audio, transición y material requerido. Distingue estimación de rodaje y código de tiempo comprobado. Para demostraciones, especifica lo que debe verse y oírse.

Para editar un audio grabado, usa [deadair.py](herramientas.md) con SRT, VTT o JSON de Whisper. Marca entrada y salida de silencios, repeticiones, muletillas, pausas con intención y retomas. Su heurística léxica es principalmente inglesa. Revisa cortes con criterio y entrega acción e intervalo.

Desde guion, entrega texto sugerido para subtítulos. Con transcripción verificada, exporta SRT/VTT con orden, intervalos y ortografía. Incluye checklist de toma, montaje y exportación.
