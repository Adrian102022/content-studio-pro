# Estrategia y calendario

Define objetivo, propuesta, público, recursos, zona horaria y frecuencia sostenible. Elige pilares con promesa reconocible y series repetibles, con acción y señal medible. Parte de una pieza principal, contabiliza rodaje y edición base una vez y revisa el historial de tema y gancho de las últimas dos semanas si existe.

Para cada fecha o semana registra canal, formato, tema, pilar, objetivo, pieza fuente, minutos, dependencia y métrica. Si hay capacidad, incluye una pieza de bajo esfuerzo y mezcla pruebas, instructivos, opiniones, historias y ofertas pertinentes. Reserva tiempo de comunidad si lo pidieron. En un plan mensual especifica las primeras piezas y revisa avances semanalmente. Señala qué es aplazable si excede la capacidad. Exporta `estrategia/calendario.csv` cuando se pidan archivos.
