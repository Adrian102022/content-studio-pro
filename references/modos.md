# Modos y carga progresiva

Consulta [rutas y reglas](../config/studio.json), o ejecuta `studio.py plan <modo-o-modulo>`. Los nombres aceptan acentos y los prefijos «modo» o «módulo». Usa `--module` para desambiguar SEO, Diseño y Humanizer. En una petición concreta carga solo la referencia aplicable.

| Modo | Resultado |
| --- | --- |
| Completo | Paquete contractual de abajo. Carga Estrategia para calendario y Analítica para métricas. |
| YouTube | Guion largo, propuesta editorial de título, SEO y guía de grabación. Abre Humanizer al finalizar el guion y Diseño si se piden imágenes. |
| Shorts | Guion vertical autónomo. Ante material fuente, abre Reutilización primero. |
| Redes | Elige la tarea en Social. |
| SEO | Optimización de títulos y metadatos. Para una revisión puntual del texto, basta SEO. |
| Diseño | Miniaturas o portadas con control visual. Consulta Títulos si hay que ajustar la pareja. |
| Humanizer | Edición respetuosa de voz y hechos. Consulta Marca si hay muestras. |
| Auditoría | Analítica para canal, perfil o publicaciones. Abre Retención si hay una serie o un gráfico. |
| Estrategia | Pilares, series y calendario según recursos. Añade evidencia de Investigación donde aplique. |
| Optimización | Define el objetivo y carga la referencia del cuello de botella. Con métricas comienza por Analítica o Retención. Devuelve el ajuste listo para aplicar y la señal a medir. |

## Contrato de Completo

1. Investiga y fija enfoque, público, promesa y evidencias. Redacta el guion completo, optimiza la apertura y edita con Humanizer.
2. Genera diez títulos y tres finalistas razonados. Empareja cada finalista con una miniatura. Produce tres archivos si hay generador y salida inspeccionable. Entrega prompts para variantes pendientes.
3. Prepara descripción, keywords principales y secundarias, tags, hashtags, CTA y comentario fijado. Incorpora capítulos cuando los tiempos se puedan verificar.
4. Desarrolla tres guiones de Shorts y una versión nativa de cada uno para TikTok e Instagram. Usa la sección fuente cuando la grabación esté pendiente.
5. Entrega storyboard, sugerencias de edición, checklist y carpeta validada con el estado de grabación, capítulos y activos. Al retomar un proyecto, reutiliza artefactos válidos y vuelve a verificar los afectados por los cambios.
