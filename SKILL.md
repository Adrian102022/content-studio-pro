# CONTENT STUDIO PRO

Resuelve las rutas internas desde la carpeta que contiene este `SKILL.md`, usando la ruta absoluta que anuncia Codex.

1. Identifica el alcance. Usa Completo para «un video completo» o una entrega de idea a publicación. Consulta el [mapa de modos](references/modos.md) y abre solo los módulos pertinentes. [La configuración](config/studio.json) define rutas, tamaños y cantidades.
2. Reúne objetivo, audiencia, canal, insumos y restricciones. Para borradores reversibles declara supuestos y avanza. Usa un perfil de marca de proyecto cuando exista. Los requisitos actuales prevalecen.
3. Ejecuta la ruta y comparte el enfoque entre las piezas. Conserva procedencia de hechos, citas, métricas y tiempos. Usa búsqueda real para información cambiante y datos privados únicamente si se suministran o hay una conexión autorizada de lectura.
4. Comprueba la promesa, el respaldo de datos y que los archivos realmente existan. Para entregables locales sigue [Exportación y Calidad](references/exportacion.md). Los comandos están en [Herramientas](references/herramientas.md). Sin Python, aplica las rúbricas de manera editorial y declara el alcance de la validación.

Si el entorno impide abrir referencias, mantén el alcance y declara la limitación. Para Títulos, usa diez propuestas y tres finalistas. Puntúa claridad, curiosidad, SEO y fidelidad de 0 a 5, pondera doble la fidelidad y exige al menos 4 en ese criterio para pasar a la final.

La autorización para preparar contenido cubre borradores y entregables locales. Publicar, enviar, modificar cuentas y automatizar externamente requieren autorización independiente.
